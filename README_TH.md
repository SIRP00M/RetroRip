# RetroRip — Pocket Studio 1.0

**แอปดาวน์โหลด เล่น และจัดเก็บสื่อบนเดสก์ท็อป ในบรรยากาศเครื่องเล่นเทปยุคเรโทร**

[English](README.md) | [ภาษาไทย](README_TH.md)

RetroRip เปลี่ยนการดาวน์โหลดและจัดระเบียบไฟล์สื่อให้เหมือนการอัดเทปเสมือนจริง มีภาพเคลื่อนไหวของกลไกเทป พร้อมหน้าจอ 5 หน้า คลังสื่อถาวร คิวดาวน์โหลด ระบบเล่นสื่อ และฉลากเทปปรับแต่งได้

> **รุ่น 1.0 นี้แจกเป็นซอร์สโค้ด** พร้อมสคริปต์ช่วยติดตั้งและสร้าง EXE บน Windows แต่ยังไม่มีไฟล์ `.exe` หรือตัวติดตั้งที่สร้างสำเร็จมาให้ ต้องติดตั้ง FFmpeg แยก และยังไม่รับรองความเข้ากันได้กับทุกระบบหรือเว็บไซต์

## ความสามารถหลัก

- **Home:** เริ่มอัดเทป ดูเทปล่าสุด หรือนำเข้าไฟล์ที่มีอยู่
- **Studio:** วาง URL อ่านข้อมูล ตั้งชื่อ/สีเทป เลือกคุณภาพ กด RECORD แล้ว KEEP
- **Collection:** ค้นหาตามชื่อหรือเจ้าของช่อง เล่นสื่อ เปิดไฟล์/โฟลเดอร์ เปลี่ยนฉลาก และเชื่อมไฟล์ที่ย้ายที่อยู่
- **Queue:** ใส่หลาย URL แยกบรรทัด แล้วประมวลผลทีละรายการ พร้อมเก็บเทปที่เสร็จโดยอัตโนมัติ
- **Settings:** ตั้งค่า Light/Dark Theme คุณภาพเริ่มต้น เสียงกลไก และโฟลเดอร์ดาวน์โหลด
- **เก็บข้อมูลถาวร:** เก็บประวัติ ภาพปก ฉลาก คิว และการตั้งค่าใน SQLite ภายในเครื่อง
- **Media Player:** เล่นสื่อผ่าน Qt Multimedia หรือเปิดด้วยโปรแกรมภายนอก
- **Offline Demo:** ทดลองหน้าตา แอนิเมชัน และเสียงตัวอย่างโดยไม่ต้องดาวน์โหลดจากอินเทอร์เน็ต

## สิ่งที่ต้องติดตั้ง

- Python **3.10 ขึ้นไป**
- Dependencies ตาม [`requirements.txt`](requirements.txt): PySide6 และ yt-dlp
- **FFmpeg ที่เรียกได้ผ่าน PATH** เพื่อรวมวิดีโอกับเสียงหรือแปลง MP3
- Codec และระบบ Multimedia ที่รองรับสำหรับการเล่นไฟล์ภายในแอป

บางเว็บไซต์อาจต้องมี JavaScript runtime เพิ่มเติมหรือการยืนยันสิทธิ์ตามข้อกำหนดของ yt-dlp และเว็บไซต์นั้น ๆ เวอร์ชันนี้ **ยังไม่มี UI สำหรับใส่บัญชีหรือ cookies** ควรดาวน์โหลดเฉพาะเนื้อหาที่มีสิทธิ์เข้าถึงและปฏิบัติตามข้อกำหนดบริการ

## เริ่มใช้งานบน Windows

1. ติดตั้ง Python 3.10+ และ FFmpeg แล้วตรวจว่าเรียก `ffmpeg` จาก Terminal ได้
2. ดาวน์โหลด/แตก ZIP ทั้งโฟลเดอร์ หรือ Clone Repository
3. ดับเบิลคลิก **`INSTALL_WINDOWS.bat`** เพื่อติดตั้ง Dependencies
4. ดับเบิลคลิก **`RUN_WINDOWS.bat`** เพื่อเปิด RetroRip

ทดลองโหมด Demo ด้วย Terminal ที่เปิดในโฟลเดอร์โปรเจกต์:

```bat
RUN_WINDOWS.bat --demo
```

## เปิดผ่าน Terminal (Windows / macOS / Linux)

```bash
python -m venv .venv
```

เปิดใช้งาน Virtual Environment:

```bash
# macOS / Linux
source .venv/bin/activate

# Windows PowerShell
# .venv\Scripts\Activate.ps1
```

แล้วติดตั้งและเปิดแอป:

```bash
python -m pip install -r requirements.txt
python src/main.py
```

ถ้า Codec หรือระบบเสียงของเครื่องไม่รองรับการเล่นผ่านแอป ให้ใช้ **••• → Open file externally**

## วิธีใช้งาน

1. เปิด **Studio** แล้ววาง URL
2. รอโหลดข้อมูลสื่อและตัวเลือกรูปแบบไฟล์
3. ตั้งชื่อฉลาก สีตลับ และคุณภาพ MP4/MP3 แล้วกด **RECORD**
4. รอการดาวน์โหลดและประมวลผลไฟล์ให้เสร็จ
5. กด **KEEP** เพื่อเก็บเข้า Collection โดยไฟล์ที่ดาวน์โหลดสำเร็จจะถูกบันทึกประวัติตั้งแต่ก่อนกด KEEP ด้วย
6. เปิด **Collection** เพื่อค้นหา เล่น เปลี่ยนชื่อฉลาก เปิดไฟล์ หรือเชื่อมตำแหน่งไฟล์ใหม่

หากต้องการใส่หลายลิงก์ ให้ไปที่ **Queue** วาง URL บรรทัดละหนึ่งรายการ กด **ADD TO STACK** และ **START QUEUE** ระบบจะทำทีละรายการ

### พฤติกรรมและข้อจำกัด

- สลับหน้าได้ขณะกำลังอัด และใช้แถบสถานะด้านล่างกลับไปยัง Studio ได้
- **PAUSE AFTER CURRENT** รอให้งานปัจจุบันเสร็จก่อนพัก ส่วน **CANCEL** ยกเลิกเฉพาะรายการนั้น
- ปุ่มบนเครื่องมี **REC**, **STOP**, **EJECT** โดย EJECT คืนเทปที่ยังไม่อัดหรือร้องขอหยุดงานที่กำลังทำ
- การเปลี่ยนฉลากมีผลเฉพาะชื่อที่แสดงใน Collection **ไม่เปลี่ยนชื่อไฟล์บนดิสก์**
- คำสั่งใน Collection ไม่ย้ายหรือลบไฟล์ต้นฉบับ
- คิวที่ค้างตอนปิดแอปจะกลับเป็นรายการรอ เมื่อเปิดใหม่ต้องกด **START QUEUE** เอง
- หากยกเลิกขณะ FFmpeg ทำงาน อาจต้องรอขั้นตอนปัจจุบันเสร็จ และอาจเหลือไฟล์ชั่วคราวหรือไฟล์ที่ทำเสร็จแล้ว
- การรวมวิดีโอกับเสียงอาจดำเนินต่อหลัง Stream ใด Stream หนึ่งแสดง 100%

## การเก็บข้อมูล

RetroRip เก็บ Collection, ภาพปก, ฉลาก, คิว และการตั้งค่าไว้ใน **SQLite** ใต้โฟลเดอร์ข้อมูลแอปของระบบ โดยเปิดตำแหน่งได้จาก **Settings → OPEN DATA FOLDER**

ค่าเริ่มต้นโฟลเดอร์ดาวน์โหลดคือ **`Downloads/RetroRip`** สามารถแก้ใน Settings

```bash
python src/main.py --data-dir /path/to/custom/catalog
python src/main.py --demo
```

`--demo` จำลองการอัดเทปและเล่นตัวอย่างเสียงสั้น ๆ ประมาณ 3 วินาที ไม่มีการดาวน์โหลดเว็บ และใช้ฐานข้อมูลทดลองแยกจาก Collection จริง เว้นแต่กำหนด `--data-dir` เอง

## สร้าง EXE บน Windows

หลังติดตั้ง Dependencies ให้รัน:

```bat
BUILD_WINDOWS_EXE.bat
```

ผลลัพธ์ที่คาดหวังคือ **`dist/RetroRip/RetroRip.exe`** หากแจกจ่าย ต้องส่ง **ทั้งโฟลเดอร์ `dist/RetroRip`** ไม่ใช่เฉพาะไฟล์ EXE และเครื่องปลายทางต้องมี FFmpeg ใน PATH

ZIP นี้มีเพียง Source และ Build Script **ยังไม่มี EXE ที่ Build แล้ว** และยังไม่ได้ยืนยันผล Build/การใช้งานจริงบน Windows สำหรับแพ็กเกจนี้

## การทดสอบ

```bash
python -m unittest discover -s tests -v
```

เอกสารที่มาพร้อมเวอร์ชัน 1.0 ระบุชุดทดสอบ Qt offscreen ครอบคลุมวงจร RECORD/KEEP/Another Tape, Queue และการสลับหน้า, ยกเลิก/ลองใหม่, ธีมและฉลากหลังเปิดใหม่, Layout สองธีม, เล่น WAV และการดาวน์โหลดจาก HTTP ในเครื่องพร้อมแปลง MP3 ผ่าน yt-dlp/FFmpeg ทั้งนี้เป็น **รายการทดสอบที่ระบุในแพ็กเกจ** ไม่ได้หมายความว่าการปรับ README ครั้งนี้ได้รันการทดสอบใหม่แล้ว

ยังไม่ได้ตรวจครบสำหรับเว็บไซต์ภายนอก เนื้อหาที่ต้องล็อกอิน อุปกรณ์เสียงบน Windows จริง และการติดตั้งในเครื่องอื่น
